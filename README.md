# Healthy Habits App

## Features
- Track daily habits
- Set reminders and notifications
- Progress visualization
- Integration with health data

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MDtechcave/Frontend.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
- Run the app:
   ```bash
   npm run serve
   ```
- Open your browser and go to `http://localhost:8080` to view the application.

## Development
- To start development, use:
   ```bash
   npm run dev
   ```
- This will enable hot-reloading for a smoother development experience.
